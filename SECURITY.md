# Seguridad

Comunica vulnerabilidades mediante un aviso privado en
[GitHub Security Advisories](https://github.com/dbravoan/dbcms-core/security/advisories).
Incluye la versión, el entorno, cómo observar el problema y su impacto. Usa datos de prueba y conserva
las credenciales fuera del aviso.
Para errores generales utiliza las issues del repositorio propietario.
